# Referensi desain

`ngulikdata-com-full-page.html` adalah template visual acuan. File ini tidak dipakai langsung di produksi. Struktur, CSS, dan tata letak diterjemahkan ke komponen di `frontend/src/components/`, dengan teks dari `content/`.

Berkas ini memuat skrip runtime dan font base64, sehingga jangan disalin ke kode produksi.
