# Integrasi

- `csv/`: parser dan validasi CSV (kontak ganda dan baris kosong dirapikan)
- `google-sheets/`: sambungan Google Sheets
- `shopee/`: impor pesanan (paket Growth ke atas)
- `whatsapp/`: notifikasi (paket Growth ke atas)
- `email/`: Resend
- `pembayaran/`: Midtrans, dinonaktifkan saat `FITUR_PEMBAYARAN_AKTIF=false`
